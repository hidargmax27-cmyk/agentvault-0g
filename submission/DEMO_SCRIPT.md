# 3-Minute Demo Script

## 0:00-0:20

Show the dashboard. State the product in one sentence:

AgentVault lets an owner give an AI agent payment authority while preserving every decision as 0G Storage memory and anchoring the proof on 0G Chain.

## 0:20-0:55

Show the policy panel:

- Monthly budget
- Current spend
- Per-payment cap
- Approved vendors

Change one value to prove the decision engine is live.

## 0:55-1:25

Show the incoming invoice. Use `0G Storage Credits` for the winning demo path. Point out the decision score and the four signals.

## 1:25-2:00

Click Deploy Ledger if the contract is not deployed yet. Show the wallet confirmation and the contract explorer link.

## 2:00-2:30

Click Upload. Show:

- 0G Storage root
- Storage transaction hash
- Explorer link

Say that the full decision context is now persisted as agent memory.

## 2:30-2:45

Click Record on 0G Chain. Show:

- Wallet confirmation
- Ledger transaction hash
- Chain explorer link

## 2:45-3:00

Close with:

This is the missing audit layer for agentic payments. Agents can act quickly, but users and merchants can verify exactly which policy, invoice, and decision produced each payment authorization.
