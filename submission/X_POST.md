Built AgentVault 0G for the 0G APAC Hackathon.

AgentVault is a self-custodial AI payment console: configure an agent's spending policy, evaluate invoices, write the decision memory to 0G Storage, then anchor the storage root on 0G Chain for an explorer-verifiable audit trail.
